# MareaNav

Prototipo de la actividad **Navegando mareas** (Arquitectura de Software, Unidad 3).

## Ejecutar

Desde esta carpeta:

```text
python -m unittest prototipo.pruebas
python -m prototipo
python -m prototipo.servidor
```

La consola queda en http://127.0.0.1:8765

## Regenerar el informe y la presentación

```text
python docs/generar_informe.py
python docs/generar_presentacion.py
```

Los archivos quedan en `entrega/`. El guion del video está en las notas de cada diapositiva.

## Video

Grabar la presentación y la demostración del prototipo (máximo 15 minutos), subir el video a YouTube como **no listado** y pegar el enlace en el informe y en el LMS. Completar en la portada los nombres del equipo.
